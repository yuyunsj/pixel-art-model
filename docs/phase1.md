# Phase 1 — Pixel Representation 계획

기준: [spec.md](spec.md)의 Phase 1. 완료 조건은 **RGBA 이미지의 토큰화와 복원이 일관되게 동작**하는 것이다.

1. 32색 고정 팔레트의 실제 RGBA 값과 투명 토큰 ID를 정의한다. 투명 픽셀은 RGB 값과 무관하게 동일 토큰으로 매핑한다.
2. 32×32 RGBA 입력의 크기·알파 정책을 검증하고, 허용 색상은 정확히 토큰으로 변환한다. 팔레트 밖 색상에 대한 양자화 방식은 대안과 손실을 기록한 뒤 선택한다.
3. 토큰을 32×32 RGBA PNG로 복원한다. 원본 해상도를 유지하고 확대 미리보기만 nearest-neighbor를 쓴다.
4. JSONL 메타데이터와 이미지 로더를 구현한다. 출처·라이선스·캐릭터 ID를 필수 관리 대상으로 둔다.
5. 투명도, 전 색상, 잘못된 크기·인덱스, PNG 저장·재로딩을 테스트한다. `decode(encode(image))`의 픽셀 단위 일치를 검증한다.

Phase 2에서 조건 인코더, 2D 위치 인코딩, Transformer, 반복 마스크 샘플링을 완성한다. 실제 데이터 학습은 Phase 3이다. Teacher–Student와 GAN은 Phase 5·6에 남긴다.
